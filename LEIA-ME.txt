CAÇADOR DE CLIENTES
===================

O que faz: a cada 10 minutos (das 7h às 23h) lê os projetos novos do 99Freelas e do Workana,
dá uma nota de 0 a 10 para cada um e manda no seu Telegram os que têm a sua cara,
junto com um rascunho de proposta pronto para copiar.
Com a chave GEMINI_API_KEY (grátis), a proposta é escrita pela IA para cada projeto;
sem ela, usa os modelos prontos.

Roda na nuvem (GitHub Actions), de graça. Não precisa deixar o notebook ligado.

COMANDOS (rodar dentro da pasta C:\Bot.ideias\cacador-clientes)
  python cacador.py --teste     mostra na tela o que ele mandaria agora (não envia nada)
  python cacador.py --ping      manda uma mensagem de teste para o seu Telegram
  python cacador.py --chat-id   descobre o seu chat_id (só na configuração)
  python cacador.py             roda de verdade uma vez (manda no Telegram)

RODAR NA HORA PELA NUVEM
  GitHub > repositório Bot_cacaTrampo > aba Actions > "Caçador de clientes" > Run workflow

AJUSTES (no começo do cacador.py)
  NOTA_MINIMA            nota mínima para avisar (hoje: 7)
  IDADE_MAX_HORAS        ignora projeto mais velho que isso (hoje: 12h)
  MAX_ALERTAS_POR_RODADA no máximo quantos avisos por vez (hoje: 8)
  SERVICOS               palavras que contam ponto para cada serviço seu
  FORA_DO_PERFIL         palavras que tiram ponto
  VETO_TITULO            palavras no título que descartam o projeto (marketing, design...)
  FACIL_PRA_VOCE         o que você já sabe fazer (ganha bônus)
  PRECOS                 faixas de preço estimadas por serviço e porte
  EXPERIENCIA / COMO_FARIA / PERGUNTA   textos usados no rascunho da proposta
